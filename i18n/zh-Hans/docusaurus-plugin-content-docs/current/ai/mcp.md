title: 连接 MCP 工具
---

## 开始前

先配置[支持工具调用的模型](models.md)，再选择可信 MCP 服务。确认端点、认证方式、权限及执行位置。外部下载或媒体处理可能发生在服务器上，而不是当前设备。

## 添加外部能力

1. 打开 **AI → 外部能力**，添加连接。
2. 填写服务说明中的 HTTP MCP 端点，以及应用支持的认证字段。网站首页不一定是 MCP 端点。
3. 测试端点并发现工具，启用前检查名称、描述和参数。
4. 先尝试只读操作，查看工具结果并处理错误，再请求修改。
5. 涉及敏感操作时，确认目标与参数正确后再批准。不再使用时移除连接。

## 结果与限制

助手可以使用受支持的工具。MCP 是工具协议，模型接口需要单独配置。客户端支持 MCP 与 JSON Schema 的一个子集，不支持的 Schema 会被拒绝；不保证支持任意 OAuth 流程、服务端请求或实验性任务扩展。

预置网络搜索连接可删除，删除后不会自动恢复。搜索会向所配置服务发送查询。外部工具运营者可能收到已授权的参数与数据，不要在提示词中写入凭据。存在源码支持不代表真实服务及所有设备均已验收。
