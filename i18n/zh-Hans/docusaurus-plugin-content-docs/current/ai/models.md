## 开始前

使用包含 AI 页面的 macOS 或 Android 构建，准备同一 OpenAI 兼容服务商的接口地址、模型名称及自己的 API Key。了解服务条款与费用。普通播放不需要模型。

## 连接与测试

1. 打开 **AI → 模型**，进入模型设置。
2. 填写来自同一服务商的 **API 域名**、**模型名称**及 **API Key**。不要把密钥粘贴进对话。
3. 保存并执行**测试连接**。仅聊天成功不代表支持工具调用，请阅读测试结果。
4. 阅读数据共享提示，先尝试一个只读的媒体库问题。
5. 修改操作执行前，检查工具名称及参数再批准；通过结果卡确认操作是否实际完成。

## 结果与限制

助手通过所配置的服务商回复。消息、选中上下文和工具结果可能发送给服务商。密钥保存在本地配置，目前没有独立系统钥匙串或应用数据库加密。请使用有限权限凭据并保护备份。

模型需要支持应用要求的聊天与工具协议。认证失败、限流和工具协议不兼容的处理不同，应查看连接测试结果。取消当前轮次不会撤销已经完成的操作。本指南未使用真实服务商账号或设备完成验收。[MCP 服务](mcp.md)提供工具，不替代推理模型。
