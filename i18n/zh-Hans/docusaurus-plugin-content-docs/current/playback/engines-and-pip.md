---

## 双播放引擎路由

OpenPlayX 内置两套原生播放引擎并自动路由：

- **`libmpv`（默认引擎）**：基于应用内置的 FFmpeg 9.1（`package-ffmpeg`），在受支持平台上优先使用。
- **`libVLC`（自动回退）**：自动接管 Tracker 音频格式、暂未提供 `libmpv` 构建的平台（当前包括 Windows），以及 `libmpv` 无法打开的媒体文件。

桌面端无需单独安装 VLC 或 mpv。

## 画中画（PiP）

点击播放器顶栏的**画中画**按钮即可进入悬浮小窗。进入或退出画中画不会重新打开视频或重建播放器，播放进度、播放/暂停状态、音轨、字幕与倍速都会完整保留。

### 各平台支持情况

| 平台 | 实现方式 | 说明与限制 |
| --- | --- | --- |
| **macOS** | 独立播放器窗口切换为置顶小窗 | 自动恢复原窗口尺寸、位置与全屏状态；按 `Escape` 优先还原。 |
| **Windows** | 独立播放器窗口切换为置顶小窗 | 自动恢复原窗口位置与置顶状态；按 `Escape` 优先还原。 |
| **Linux（X11）** | GTK 置顶小窗 | 保留系统标题栏用于拖动与关闭；置顶行为取决于窗口管理器。 |
| **Android** | 系统画中画（视设备能力而定） | 需手动点击按钮进入，不会自动拦截 Home 键。 |
| **iOS / iPadOS 15+** | 基于 `libmpv` 的 AVKit 系统画中画 | 触发 `libVLC` 回退时不显示入口；提供基础播放/暂停控制。 |
| **Linux Wayland / tvOS** | 不显示入口 | 当前未提供原生画中画实现。 |

桌面端仅独立播放器窗口支持画中画（嵌在主界面中的播放区域不会缩小整个窗口）。在应用处于后台时关闭系统画中画小窗，播放会自动暂停，避免声音继续在后台播放。
