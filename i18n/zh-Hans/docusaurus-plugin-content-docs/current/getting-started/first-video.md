title: 播放第一个视频
---

## 开始前

准备已发布的 macOS Apple Silicon 或 Android 安装包、相应设备，以及有权播放的视频。保留足够存储空间，只授予需要的媒体访问权限。

## 安装与播放

1. 打开[下载页](https://openplayx.com/zh/download/)，选择平台与架构，按照该版本的说明安装。
2. 启动 OpenPlayX，使用打开文件操作，通过系统文件选择器选择测试视频。也可以在**来源**中添加连接后浏览。
3. 选择视频开始播放，尝试暂停、拖动进度、音量，以及文件提供的音轨和字幕。
4. 停止播放并返回应用。若要整理收藏，请[添加媒体库目录](../library/home.md)。

## 结果与限制

视频在设备上播放。扫描或打开网络视频不会生成永久离线副本。文件权限和编解码支持取决于平台与构建；网络来源需要自己的凭据。AI 配置为可选步骤。

失败时先测试一个已知正常的小型本地文件，再检查文件权限和版本说明，最后[反馈问题](../help/faq.md)。步骤已核对实现，但不代表所有格式或设备均已验证。
