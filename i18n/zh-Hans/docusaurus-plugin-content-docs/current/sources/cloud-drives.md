---
title: 网盘来源
---

OpenPlayX 内置了品牌 WebDAV 网盘预设，以及面向主流云盘的只读 OAuth 适配器。

## WebDAV 预设（坚果云 / 123 云盘）

- **坚果云**：打开**来源 → 添加 → WebDAV**，选择**坚果云**预设（默认地址 `https://dav.jianguoyun.com/dav/`），填写账号与**第三方应用密码**（不要使用主登录密码）。
- **123 云盘**：打开**来源 → 添加 → WebDAV**，选择**123 云盘**预设。确认账号已开通 WebDAV 权限后，从官方控制台复制端点地址与凭据填入。

## OAuth 网盘（OneDrive / Dropbox / 百度网盘）

1. 打开**来源 → 添加**，选择 **OneDrive**、**Dropbox** 或 **百度网盘**。
2. 通过系统浏览器完成授权登录（不使用应用内嵌网页）：
   - **OneDrive** 仅支持个人微软账号。
   - **Dropbox** 使用完整 Dropbox 只读权限。
   - **百度网盘**使用浏览器授权，依赖发布方配置获批应用与服务端授权桥接。
3. 浏览并进入想要作为根目录的文件夹，保存连接。
4. 在已保存的连接下添加**文件来源**，即可[扫描入库](../library/home.md)。

支持添加多个网盘账号，每个连接独立保存凭据与目录范围。

## 安全存储、播放与平台限制

- **系统安全存储**：OAuth 访问/刷新令牌以及新版品牌 WebDAV 应用密码保存在系统安全存储中（如 macOS 钥匙串），不会出现在配置导出或 AI 工具结果中。
- **直连播放**：播放经由本机回环网关按需获取临时签名链接，视频流量不经过 OpenPlayX 公共服务器。
- **断开账号**：在连接表单点击**断开账号**（或删除来源）会立即清除本地凭据并中断播放。如需彻底撤销平台授权，请同时前往微软、Dropbox 或百度账号的第三方应用管理页面移除 OpenPlayX。
- **平台与验收范围**：原生 OAuth 登录目前支持 macOS、iOS/tvOS（附近设备认证）与 Android，且依赖构建中配置发布方 OAuth 客户端；Linux 与 Windows 当前仅支持 WebDAV 预设。部分网盘的真实账号验收仍在进行中。
