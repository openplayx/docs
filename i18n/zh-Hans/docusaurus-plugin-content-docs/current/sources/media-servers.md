---
title: 媒体服务器与网络协议
---

除 [SMB 共享](smb.md)外，OpenPlayX 还支持直接连接个人媒体服务器、常见网络文件协议以及本地光盘目录。

## 媒体服务器（Jellyfin / Plex / Emby）

1. 打开**来源 → 连接**，新增 **Jellyfin**、**Plex** 或 **Emby** 连接。
2. 填写服务器地址并完成登录或输入凭据/令牌。
3. 测试连接并保存后，可直接浏览媒体库，或将其加入**首页**。

### Jellyfin 播放协商与自动回退

播放 Jellyfin 视频时，OpenPlayX 会携带已选媒体源与原生设备配置向服务器请求 `PlaybackInfo`：

- 服务器判定兼容时优先使用 **Direct Play** 原流直放。
- 不兼容时自动使用服务器提供的渐进 HTTP **转封装（Remux）**或**转码（Transcode，MPEG-TS）**地址；若原生播放器打开初始流失败，最多自动触发一次服务器回退重试。
- 所有播放流量均经由本机回环网关代理，API Key 仅留在认证请求头中，不会出现在播放地址里，重定向也不会携带凭据。
- 若服务器对某条目仅提供 HLS 流，应用会给出明确错误提示，而不会直接转发无法鉴权的分段清单。

## 其他网络协议与本地光盘

在**来源 → 连接**中还可添加：

- **WebDAV**：适用于 NAS 的 WebDAV 服务及网盘 WebDAV 预设（参见[网盘来源](cloud-drives.md)）。
- **FTP / SFTP**：连接标准文件服务器；在 [MCP 工具](../ai/mcp.md)中开启 `source.write` 后，SFTP 还支持保存外部下载文件。
- **S3 兼容对象存储**：填写端点与凭据以访问个人存储桶。
- **DLNA**：自动发现同一局域网内的媒体服务器。
- **本地光盘**：在受支持平台上支持发现本地光盘目录结构。

不同协议与服务器支持的浏览、扫描、搜索与写入能力有所差异。排查[远程访问](../remote-access/connector.md)问题前，请先确保同一局域网内可正常连接与播放。
