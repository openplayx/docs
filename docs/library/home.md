title: Build your Home library
---

## Before you start

Use a published macOS or Android build and a working local or network connection. Prepare a small folder of authorized test media; scanning a large NAS can take time.

## Add a folder and scan

1. Under **Sources**, verify that the connection can browse the folder.
2. Add the folder as a **File source**, choosing the appropriate library/media scope offered by your build.
3. Start scanning and check the task result. Return to **Home** to browse the indexed movies or series.
4. Open a title, check its files, seasons and episodes, and select a resource to play.
5. Review ambiguous metadata matches. Use the available match-correction controls rather than renaming unrelated media to force a result.

## Expected result and limits

Home shows indexed media, artwork and watch progress where available. Scanning reads media information; it does not copy all videos. Online matching requires network access and may be wrong. NFO files and local artwork can influence metadata. Keep a backup before bulk changes.

The library is local to this installation. Full cross-device synchronization is not delivered. Development database upgrades can recreate older tables and discard records, conversations or progress; lossless migration is not guaranteed. Device and source combinations require their own validation.
