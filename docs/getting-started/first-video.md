## Before you start

Use a published macOS Apple Silicon or Android build, a supported device and a video you are authorized to play. Have enough local storage and grant access only to the media you need.

## Install and play

1. Open the [download page](https://openplayx.com/download/) and choose your platform and architecture. Follow that release's installation notes.
2. Launch OpenPlayX. Use the open-file action and select your test video through the system file picker. Alternatively, add a connection under **Sources** and browse it.
3. Select a video to start playback. Try pause, seeking, volume, audio track and subtitle selection where the file provides them.
4. Stop playback and return to the app. For a browsable collection, [add a library folder](../library/home.md).

## Expected result and limits

The selected video plays on your device. Scanning or opening a network video does not download a permanent offline copy. File access and supported codecs depend on the platform and build; source adapters need their own credentials. AI setup is optional.

If a video fails, try a small known-good local file first. Check file permissions and the release's platform notes before [reporting a problem](../help/faq.md). These steps have been checked against the implementation; this guide does not certify every codec or device.
